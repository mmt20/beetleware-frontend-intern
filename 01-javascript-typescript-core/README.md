# JavaScript + TypeScript Core - 9 Days

Master JavaScript fundamentals and TypeScript basics through hands-on practice.

---

## 📅 Overview

**Duration:** 9 days (7 JS + 2 TS)  
**Format:** Daily concepts → exercises → deliverables

### What You'll Build

- Type coercion cheatsheet
- Collection utilities library
- Closure-based helpers
- Event loop diagrams
- HTTP client + TODO app
- Typed utility functions

## 🗓️ Daily Plan

### Week 1: JavaScript Fundamentals

#### Day 1: Values, Types & Variables

**Learn:** Primitives, type coercion, `let`/`const`/`var`, hoisting  
**Practice:** Coercion drills, refactor code  
**Build:** Types & coercion cheatsheet

#### Day 2: Control Flow + Arrays & Objects

**Learn:** `if`/`switch`/loops, array methods, spread/destructuring  
**Practice:** `map`/`filter`/`reduce`, safe object merges  
**Build:** Collection utilities library

#### Day 3: Functions, Scope & Closures

**Learn:** Function types, lexical scope, closures  
**Practice:** Build `counter()`, `once()`, `memoize()`  
**Build:** Closure-based helper functions

#### Day 4: `this`, Prototypes & Object Model

**Learn:** `this` binding, `call`/`apply`/`bind`, prototype chain  
**Practice:** Constructor patterns, method borrowing  
**Build:** Examples with correct `this` usage

#### Day 5: Event Loop (Foundations)

**Learn:** Call stack, task/microtask queues, timers  
**Practice:** Predict output puzzles  
**Build:** Event loop timeline notes

#### Day 6: Event Loop (Rendering & Performance)

**Learn:** Frames, long tasks, `requestAnimationFrame`  
**Practice:** Fix UI jank, implement debounce/throttle  
**Build:** Performance analysis report

#### Day 7: Async JavaScript

**Learn:** `async`/`await`, `AbortController`, error handling  
**Practice:** Build HTTP client, create TODO app  
**Build:** `httpClient.js` + working app

### Week 2: TypeScript

#### Day 8: TypeScript Fundamentals

**Learn:** Type inference, unions/intersections, `tsconfig.json`  
**Practice:** Convert JS utilities to TypeScript  
**Build:** Typed utilities + config

#### Day 9: Objects, Functions & Generics

**Learn:** Interfaces vs types, generics, utility types  
**Practice:** Create generic `Result<T>`, typed helpers  
**Build:** Type-safe utility library

# BW Frontend Intern Program

## Program Structure

MY 4-month journey at BW

JavaScript ES6+, JSX, Props, State, Events, Hooks, Tailwind CSS, and a mini project.

### Month 2 – Advanced React & Next.js

Redux Toolkit, React Query, Next.js Routing & API, SSR/SSG/ISR, and a Blog Platform project.

### Month 3 – Professional Practices

NextAuth Authentication, Performance Optimization, Accessibility (WCAG), Testing (Jest & Cypress), and Deployment on Vercel.

### Month 4 – Capstone Project

Build and deploy a Full E-Commerce Store using Next.js, Redux, and Stripe.

## 📋 Project Guidelines

### General Requirements

**All projects must include:**

✅ Clean, semantic HTML  
✅ Responsive design (mobile-first)  
✅ Accessibility compliance (WCAG AA)  
✅ Git version control  
✅ README with documentation  
✅ Live demo (GitHub Pages, Netlify, Vercel)  

### Code Quality Standards

- **HTML:** Valid HTML5, semantic elements
- **CSS:** BEM naming, organized structure
- **JavaScript:** ES6+, clean code, comments
- **Git:** Meaningful commits, proper branching

### Performance Targets

- **Lighthouse Score:** 90+ in all categories
- **LCP:** < 2.5s
- **FID:** < 100ms
- **CLS:** < 0.1

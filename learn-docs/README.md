Each topic includes:

- **`hands-on.md`** — Practical exercises and coding challenges

---

## 🎯 Topics Covered

### 1. HTML5 & Semantic Markup
**Master modern HTML5 features and semantic web development**

- Semantic elements and document structure
- Forms, validation, and accessibility
- Media elements (audio, video, canvas)
- Web APIs and storage
- SEO best practices

### 2. CSS3 & Modern Layouts
**Build responsive, beautiful interfaces with modern CSS**

- Flexbox and Grid layouts
- Responsive design and media queries
- Animations and transitions
- CSS custom properties (variables)
- Modern CSS architecture (BEM, SMACSS)

### 3. JavaScript ES6+
**Write modern, efficient JavaScript code**

- ES6+ syntax and features
- Async programming (Promises, async/await)
- DOM manipulation and events
- Modules and bundling
- Error handling and debugging

### 4. Git & Version Control
**Professional version control workflows**

- Git fundamentals and commands
- Branching strategies (Git Flow, GitHub Flow)
- Collaboration workflows
- Resolving conflicts
- Best practices and conventions

### 5. Web Performance
**Optimize for speed and user experience**

- Performance metrics (Core Web Vitals)
- Loading optimization techniques
- Image and asset optimization
- Caching strategies
- Performance monitoring tools

### 6. Web Accessibility (A11y)
**Build inclusive web experiences**

- WCAG guidelines and standards
- Semantic HTML for accessibility
- ARIA roles and attributes
- Keyboard navigation
- Screen reader compatibility
